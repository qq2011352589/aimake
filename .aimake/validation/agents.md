# agents.md — validation 的知识边界
## OVERVIEW
本目录是 aimake（知识树生成器）在真实项目 `wap`（TypeScript）上的验证/评测场所，记录盲测结论、指标与缺陷，用于回答"aimake 的承诺是否成立、精度瓶颈在哪、有什么缺陷要修"。核心结论：可达性 100%，但精度受轻量档阈值限制（50% 精确导航），且符号自检存在高误报缺陷。

## FILES
- `REPORT.md`：aimake 对 `wap` 的完整验证报告——盲测设计（Agent A 真值 / Agent B 盲测）、逐题评分表、结论（NEEDS WORK）、关键发现 F1-F5 及按杠杆排序的修复建议、复现命令；是了解 aimake 实际能力与已知缺陷（轻量档过激、反引号未剥离导致自检误报、跨目录契约过度泛化、源码漂移）的入口文档。
